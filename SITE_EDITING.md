# QuMLa Homepage Editing Map

Main pages:

- Home: `_pages/about.md`
- Publications: `_pages/publications.md` and `_bibliography/papers.bib`
- About Me: `_pages/about_me.md`
- Members: `_pages/members.md`
- News: `_news/`
- Notice: `_pages/notice.md`

Images:

- Main logo: `assets/img/qumla-full.png`
- Favicon/logo icon: `assets/img/qumla-only-logo.svg`
- Profile image placeholder: `assets/img/profile-placeholder.svg`

To use your real profile photo, add the image to `assets/img/` and update the image path in `_pages/about_me.md`.

Site-wide settings:

- Group name, description, footer, and deployment URL: `_config.yml`

Deployment:

- Pushing to `main` triggers `.github/workflows/deploy.yml`.
- The live site is `https://wookshin26.github.io`.
